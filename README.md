# RIFT//LAB 怀旧服构筑工作台

面向英雄联盟怀旧服的网页构筑工具，包含 60 位经典英雄、50 个符文、
56 个天赋、16 个召唤师技能和 152 件经典装备。无需登录，打开公开网址
即可使用。

## 直接使用

公开网站：

<https://lgsszh.github.io/lol-traditional/>

普通用户不需要安装 Node.js，也不需要打开命令行窗口。首次进入网站会
显示新手指引；之后可点击右上角“使用帮助”重新查看。

## 主要功能

- 按位置、中文名、称号、英文名和职业搜索经典英雄；
- 手动配置完整的 30 枚经典符文，并实时计算属性总计；
- 分配 30 点经典天赋；
- 使用经典技能图标与经典英雄原画，查看 60 位英雄的被动与 Q/W/E/R 详情、逐级伤害公式、冷却、消耗和施法距离，并编辑 18 级技能加点；
- 选择召唤师技能和六格出装，按 6 个等级分类、14 种属性和关键词筛选 152 件装备，查询属性、价格、游戏式合成树与后续升级；
- 在浏览器本地保存构筑并生成可分享链接；
- 使用内置规则生成 AI 构筑草案。

## 本地开发

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

开发服务器只应在开发期间运行。请勿将本地服务器设置成开机启动或每
分钟自动重启。

常用命令：

- `npm test`：运行搜索筛选测试、Vinext 构建和服务端渲染测试；
- `npm run lint`：运行 ESLint；
- `npm run build`：生成 Vinext 生产构建；
- `npm run build:pages`：生成 GitHub Pages 静态站点（由工作流设置环境变量）。
- `npm run data:update`：重新读取 OP.GG Classic 与 Riot 历史数据并生成本地快照；
- `npm run data:check`：在线重新生成并确认仓库快照没有漂移。

## 清理旧版后台任务

早期本地版本曾安装 `RIFT-LAB Local Server` 和
`RIFT-LAB Local Server Watchdog` 两个 Windows 计划任务，可能造成
开机或每分钟弹出黑色命令行窗口。

如仍受影响，以管理员身份运行：

```powershell
.\uninstall-background.cmd
```

清理后普通用户应始终使用上面的公开网址。
