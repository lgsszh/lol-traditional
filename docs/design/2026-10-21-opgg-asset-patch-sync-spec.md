# OP.GG 统计与图标版本分离后的每日同步修复

## 目标与事实

用户要求继续修复每日 sync。2026-10-21 失败运行 39576691645 在生成海斗 OP.GG 构筑时停止，报 `Unexpected OP.GG asset patch 16.20.1 for statistics patch 16.21`。77 英雄、63 符文、154 装备及现代技能生成此前均通过；不是名单扩容或网络错误。

实时 OP.GG 怀旧海斗首页标题和 query.patch 为 16.21，冠军图标来自 16.20.1，页面同时明确 `metaLatestVersion:16.20`。图标版本属于网站资源元数据，不能强制当成统计版本，更不能因此将旧数值冒充最新。

## 本次范围

- 从 OP.GG 源页分别获取统计补丁、图标完整版本及资源元数据版本。资源落后仅在元数据与图标大/小补丁完全一致，且资源不超前于统计时接受；未知、缺失证据的错位、混杂资源版本仍失败。
- 统计补丁仍必须与所选 Riot / CommunityDragon 的数值版本约束兼容；各英雄详情页继续验证 canonical、模式、英雄身份及统计补丁，不准用旧图标路径代替统计证据。
- 真实图标 URL、资源版本、统计版本分别保存，不改写 URL 伪造版本。保持完整构筑、轻量排行及按需 JSON 同批生成；保留英雄名单、数值、来源和数据质量门禁。
- 新增回归测试覆盖同版、元数据确认的旧图标、新补丁通用情况、缺失/矛盾元数据、超前资源、混杂版本、数值来源落后及英雄页统计身份校验。无需 UI 重做、不修改网络代理，不手改生成数据。
